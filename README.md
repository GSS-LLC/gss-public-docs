# GSS Public Documentation

## დანიშნულება

ეს არის GSS პროდუქტების ერთიანი, საჯარო ცოდნის ბაზა. მისი მიზანია მომხმარებელმა — ბუღალტერმა, მენეჯერმა,
ადმინისტრატორმა ან მხარდაჭერის თანამშრომელმა — კოდის, შიდა სისტემების ან ტექნიკური გუნდის ჩართვის გარეშე შეძლოს
პროდუქტის ფუნქციის გაგება და ყოველდღიურ საქმეში გამოყენება.

აქ იწერება:

- რას აკეთებს პროდუქტი და რომელი სამუშაო ამოცანისთვის გამოიყენება;
- როგორ გამოიყენოს მომხმარებელმა ეკრანები, ველები, ფილტრები და ძებნა;
- რეალური, ადამიანურად წასაკითხი მაგალითები და მოქმედების შეზღუდვები.

აქ არ იწერება კოდის არქიტექტურა, API/SQL/Spanner-ის ტექნიკური დეტალები, ინფრასტრუქტურული ოპერაციები ან შიდა
გადაწყვეტილებები. ასეთი მასალა ცალკე gss-private-docs-ში ინახება.

## ორგანიზება

ყველა დოკუმენტი პროდუქტის მიხედვითაა დაჯგუფებული GSS Products-ში. პროდუქტისგან
დამოუკიდებელი წესები — მაგალითად, საძიებო ფრაზის საერთო წესები —
ინახება `General`-ში და პროდუქტების გვერდები მასზე მიუთითებს.

საძიებო გზამკვლევები:

- Contacts — კონტაქტები;
- Contacts — კომუნიკაციის ისტორია;
- SuperFin — ანგარიშთა გეგმა, საწყისი ნაშთები და ბრუნვა;
- SuperFin — საბუთები;
- SuperFin — RS ანგარიშ-ფაქტურები.

SuperFin-ის სხვა გზამკვლევები:

- [მონაცემების შენახვა უმოქმედობისას](<GSS Products/SuperFin/organization-inactivity.md>) — მხოლოდ SuperFin-ის
  აქტივობის ვადა, გაფრთხილებები, შენახვის მონიშვნა, ავტომატური გათიშვა და აღდგენა.

კალკულატორის მიერ მხარდაჭერილი GSS-ის პროგრამებისთვის საერთო გზამკვლევები:

- [ორგანიზაციის მონაცემები შეძენილი მეხსიერების გადაუხდელობისას](<GSS Products/General/organization-nonpayment.md>) —
  შეძენილი მეხსიერების ვადა და თავისუფალი ადგილი, გაფრთხილებები, შვიდი მხარდაჭერილი პროგრამის გათიშვა, აღდგენა და
  საბოლოო ფიზიკური წაშლა.
- [ორგანიზაციის გამოყენებული მეხსიერების დათვლა](<GSS Products/General/storage-usage.md>) — მონაცემებისა და
  ფაილების მოხმარება, პროგრამების ჭრილი, შეძენის ბიჯი, საერთო ანგარიშის განაწილება, ატვირთვის ლიმიტი და განახლების დრო.

Supports-ის გზამკვლევები:

- Q&A საბუთები — როლები და წვდომა.
