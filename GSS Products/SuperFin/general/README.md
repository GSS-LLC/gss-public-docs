# SuperFin — ზოგადი გზამკვლევი (აღწერა, ინსტრუქციები და ფასები)

ეს საქაღალდე აერთიანებს საბუღალტრო აღრიცხვის პროგრამა **SuperFin**-ისა და **ვებ-სუპერფინის (`superfin.gss.ge`)** ოფიციალურ საჯარო დოკუმენტაციას (`https://gss.ge/SuperFin` გვერდების მიხედვით): პროგრამის შესაძლებლობების სრულ აღწერას, სასწავლო და თემატურ ვიდეო ინსტრუქციებს, გადმოსაწერ რესურსებსა და მომსახურების ფასებს.
