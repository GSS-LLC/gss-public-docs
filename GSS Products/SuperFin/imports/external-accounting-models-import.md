# ვებ-სუპერფინი: სხვა პროგრამებიდან მონაცემების იმპორტი — ორისის მოდელები

## იმპორტის მოდელის არჩევა და საკუთარი ასლის მომზადება

სხვა საბუღალტრო პროგრამებიდან (მათ შორის „ორისიდან“) ანგარიშთა გეგმის, საწყისი ნაშთებისა და გატარებების გადმოსატანად ვებ-სუპერფინი იყენებს Google Sheets-ის სპეციალურ იმპორტისა და კონვერტაციის მოდელებს:

1. ვებ-სუპერფინის მარცხენა მენიუში გახსენით **„იმპორტის მოდელები“** — გვერდზე განთავსებულია ოფიციალური Google Drive საქაღალდის ბმული: ['სუპერფინის მოდელები' - Google Drive Excel-ში](https://drive.google.com/drive/folders/1DzF9BqU7wU-h9a1xo3Sh0Abxki9YBBiS?usp=sharing) (თავად ვებ-სუპერფინის გვერდი მოდელების შიდა რედაქტორი არ არის).
2. საქაღალდეში ხელმისაწვდომია 4 ქართულენოვანი შაბლონი, რომლებიც დანიშნულებით განსხვავდება:
   - **პირდაპირი იმპორტის მოდელები (ვებ-სუპერფინში API-ით ჩასატვირთად)**:
     - [ორისის ანგარიშებისა და საწყისი ნაშთების პირდაპირი იმპორტის მოდელი](https://docs.google.com/spreadsheets/d/1z_04gbNQBJlWNjhvlg5lnlzOsDQAMJdSmNdbbv3wjak/edit) (ღილაკით **„იმპორტის შესრულება“**);
     - [ორისის გატარებების პირდაპირი იმპორტის მოდელი](https://docs.google.com/spreadsheets/d/1WFG92d6BOYkJrjyd2KxBXcJ-8lNwQ87Vro-ETkW2Ipg/edit) (ღილაკით **„იმპორტის შესრულება“**).
   - **კონვერტაციის მოდელები (API-ის გარეშე გარდაქმნისთვის)**:
     - [ორისის ანგარიშების კონვერტაციის მოდელი](https://docs.google.com/spreadsheets/d/1KY4cPWDLmZ4s6hw8WuwHXjg-qdbyTBVagp4nXzVn4ns/edit) (ღილაკით **„კონვერტაცია“**);
     - [ორისის გატარებების კონვერტაციის მოდელი](https://docs.google.com/spreadsheets/d/1WIcEynWm_wzNhyLkbCS33vKwAhPl9BOZR3bWxACPKlo/edit) (ღილაკით **„კონვერტაცია“**).
3. გახსენით სასურველი შაბლონი Google Sheets-ში და მენიუდან **File → Make a copy** შექმენით საკუთარი სამუშაო ასლი თქვენს Google Drive-ზე.
4. **უსაფრთხოების წესი**: სამუშაო ასლის შექმნის შემდეგ გადაამოწმეთ მისი გაზიარების პარამეტრები Google Drive-ში — ფაილი, რომელშიც თქვენი ორგანიზაციის პირადი API გასაღები და საიდუმლო კოდი (`secret`) წერია, არ გააზიაროთ საჯაროდ.

ვიდეო-ინსტრუქციები იხილეთ ბმულებზე:

## პირადი API გასაღების მითითება პირდაპირი იმპორტის მოდელში

პირდაპირი იმპორტის ორივე მოდელი (ანგარიშების და გატარებების) ვებ-სუპერფინს უკავშირდება პირადი Web API გასაღებით:

1. წინასწარ დარწმუნდით, რომ ვებ-სუპერფინის ორგანიზაციაში შექმნილია **მინიმუმ ერთი პროექტი** (სერვერული იმპორტი ნაგულისხმევად იყენებს ორგანიზაციაში არსებულ უმცირესი ID-ის მქონე პროექტს; იხილეთ [პროექტების მართვა](https://supports.gss.ge/ka/info/public-qa-document/68/bc46c49a-d80b-41ea-982e-6635fab704cf)).
2. ვებ-სუპერფინში შექმენით პირადი API გასაღები და მიიღეთ საიდუმლო კოდი (`Secret`) ელფოსტაზე გამოგზავნილი 15-წუთიანი ერთჯერადი ბმულით (მიმდინარე წესები იხილეთ გზამკვლევში [დაკავშირებული პროგრამები — სუპერფინი და Web API](https://supports.gss.ge/ka/info/public-qa-document/68/3a0c705f-51f2-4287-9260-588d291d69cb); გაითვალისწინეთ, რომ ძველ ვიდეო-ინსტრუქციაში ნაჩვენები ინტერფეისი განსხვავდება მიმდინარე პირადი API გასაღების შექმნის ნაბიჯებისგან).
3. გახსენით თქვენს Google Drive-ზე შენახული პირდაპირი იმპორტის მოდელის ასლი, გადადით ფურცელზე **`parameters`** და შეავსეთ შემდეგი უჯრები:
   - **`B2` (`ორგანიზაციის ID`)** — თქვენი ორგანიზაციის იდენტიფიკატორი ვებ-სუპერფინში;
   - **`B3` (`api_key`)** — თქვენი პირადი API გასაღები;
   - **`B4` (`secret`)** — ერთჯერადი ბმულით მიღებული საიდუმლო კოდი.
   - უჯრა **`B5` (`access_token`)** განკუთვნილია სკრიპტის მიერ ავტორიზაციისას მიღებული ტოკენისთვის — მას ხელით ნუ შეავსებთ.

## ორისის ანგარიშები და საწყისი ნაშთები — პირდაპირი იმპორტი

[ორისის ანგარიშების პირდაპირი იმპორტის მოდელით](https://docs.google.com/spreadsheets/d/1z_04gbNQBJlWNjhvlg5lnlzOsDQAMJdSmNdbbv3wjak/edit) ანგარიშთა გეგმისა და საწყისი ნაშთების ვებ-სუპერფინში გადმოსატანად:

1. **წინაპირობა**: დარწმუნდით, რომ ვებ-სუპერფინის ორგანიზაციაში არსებობს **მინიმუმ ერთი პროექტი** ([პროექტების მართვა](https://supports.gss.ge/ka/info/public-qa-document/68/bc46c49a-d80b-41ea-982e-6635fab704cf)) და მომზადებული გაქვთ პირადი API გასაღების მონაცემები.
2. „ორისიდან“ თითოეული ვალუტის საწყისი ნაშთები დააექსპორტეთ ცალ-ცალკე და გამორიცხეთ `B` ანგარიშების ჩანაწერები.
3. ჩააკოპირეთ ექსპორტირებული მონაცემები მოდელის ფურცელზე **„ორისის - ანგარიშთა გეგმა“**.
4. გადადით ფურცელზე **`parameters`**:
   - შეავსეთ და გადაამოწმეთ `B2` (`ორგანიზაციის ID`), `B3` (`api_key`) და `B4` (`secret`);
   - უჯრაში **`B12` (`საწყისი ნაშთების ვალუტა`)** ნაგულისხმევად წერია `GEL` — თუ სხვა ვალუტის საწყის ნაშთებს ტვირთავთ, ჩაწერეთ შესაბამისი ვალუტის კოდი (მაგალითად, `USD`, `EUR`).
5. დააჭირეთ ღილაკს **„იმპორტის შესრულება“** (გაშვებისას Google Sheets-მა შეიძლება მოითხოვოს სკრიპტის ავტორიზაცია; იხილეთ [Google Sheets რეპორტების სკრიპტის ავტორიზაცია](https://supports.gss.ge/ka/info/public-qa-document/68/198-UrxHcaeaIOp--eioWPKEYPin8FxHDg70ysUy-jXU)).
6. შესრულების შედეგი და შესრულებული ქმედებები აისახება **`parameters`** ფურცლის **`A14/B14` (`შესრულების შედეგი`)** და **`A16/B16` (`შესრულებული ქმედებები`)** არეებში.
7. გაითვალისწინეთ, რომ მოდელით იმპორტირებული ანგარიშები იქმნება ან ახლდება აქტიურ მდგომარეობაში (არქივის ნიშანი იხსნება). თუ გსურთ ვებ-სუპერფინის სტანდარტული Excel ფაილით იმპორტი, იხილეთ [ანგარიშებისა და საწყისი ნაშთების Excel იმპორტი](https://supports.gss.ge/ka/info/public-qa-document/68/8756f99c-bff2-452e-9134-5e0b215f9fa7).

## ორისის გატარებები — პირდაპირი იმპორტი

[ორისის გატარებების პირდაპირი იმპორტის მოდელით](https://docs.google.com/spreadsheets/d/1WFG92d6BOYkJrjyd2KxBXcJ-8lNwQ87Vro-ETkW2Ipg/edit) საბუღალტრო ოპერაციების ვებ-სუპერფინში გადმოსატანად:

1. **წინაპირობა**: გატარებების იმპორტამდე ვებ-სუპერფინში უკვე უნდა არსებობდეს გატარებებში გამოყენებული ყველა საბუღალტრო ანგარიში და არცერთ მათგანს არ უნდა ჰქონდეს ქვეანგარიშები (ოპერაცია იწერება მხოლოდ საბოლოო, ქვეანგარიშების არმქონე ანგარიშებზე). ასევე ორგანიზაციაში უნდა არსებობდეს მინიმუმ ერთი პროექტი.
2. „ორისიდან“ გატარებები დააექსპორტეთ ნომინალურ ვალუტაში (არჩევანით **„ნომინალში“**) და უცვლელად ჩააკოპირეთ მოდელის ფურცელზე **„ორისის - გატარებები“**.
3. ფურცელზე **`parameters`** შეავსეთ `B2` (`ორგანიზაციის ID`), `B3` (`api_key`) და `B4` (`secret`). უჯრა **`B11` (`სუპერფინი დაკავშირებულია`)** ასახავს ორგანიზაციის კომპიუტერის სუპერფინთან კავშირის მონაცემს — მას ხელით თვითნებურად ნუ შეცვლით.
4. დააჭირეთ ღილაკს **„იმპორტის შესრულება“** (საჭიროებისას Google Sheets-მა შეიძლება მოითხოვოს სკრიპტის ავტორიზაცია) და დაელოდეთ დასრულებას.
5. შეამოწმეთ სტატუსი **`parameters`** ფურცლის **`A14/B14` (`შესრულების შედეგი`)** და **`A16/B16` (`შესრულებული ქმედებები`)** არეებში.

## ორისის ანგარიშებისა და გატარებების კონვერტაციის მოდელები

თუ მონაცემების გარდაქმნა გსურთ პირდაპირი Web API კავშირის გარეშე, საქაღალდეში ხელმისაწვდომია ცალკე კონვერტაციის მოდელები:

- **[ორისის ანგარიშების კონვერტაციის მოდელი](https://docs.google.com/spreadsheets/d/1KY4cPWDLmZ4s6hw8WuwHXjg-qdbyTBVagp4nXzVn4ns/edit)**:
  1. ფურცელზე **„ორისის - ანგარიშთა გეგმა“** ჩააკოპირეთ ორისიდან ექსპორტირებული ინფორმაცია (`B` ანგარიშების ჩანაწერების გარეშე, როგორც ეს მითითებულია `A1` უჯრაში).
  2. ფურცელზე **`parameters`** უჯრაში **`B2` (`საწყისი ნაშთების ვალუტა`)** მიუთითეთ ვალუტა (ნაგულისხმევად `GEL`).
  3. დააჭირეთ ღილაკს **„კონვერტაცია“** — შედეგი და შესრულებული ქმედებები გამოჩნდება `A4/B4` და `A6/B6` უჯრებში.
- **[ორისის გატარებების კონვერტაციის მოდელი](https://docs.google.com/spreadsheets/d/1WIcEynWm_wzNhyLkbCS33vKwAhPl9BOZR3bWxACPKlo/edit)**:
  1. ფურცელზე **„ორისის - გატარებები“** ხელუხლებლად ჩააკოპირეთ ორისიდან ნომინალურ ვალუტაში (არჩევანით **„ნომინალში“**) ექსპორტირებული გატარებები (`A1` უჯრის მითითების შესაბამისად).
  2. ფურცელზე **`parameters`** დააჭირეთ ღილაკს **„კონვერტაცია“** — შედეგი და შესრულებული ქმედებები გამოჩნდება `A2/B2` და `A4/B4` უჯრებში.

> **შენიშვნა:** კონვერტაციის ეს ორი მოდელი ასრულებს მხოლოდ შაბლონში მონაცემების გარდაქმნას (Web API კავშირის გარეშე) და არ წარმოადგენს ვებ-სუპერფინის პირდაპირი API იმპორტის ან ჩვეულებრივი ანგარიშების Excel იმპორტის სავალდებულო შუალედურ ნაბიჯს.

## შედეგების შემოწმება, ნაწილობრივი შესრულება და ხელახალი მცდელობა

მოდელებით იმპორტისას აუცილებლად გაითვალისწინეთ შესრულების წესები:

- **ნაწილობრივი შესრულება შეცდომის დროს**:
  - პირდაპირი ანგარიშების იმპორტისას ანგარიშის შექმნა/განახლება და მისი საწყისი ნაშთის ჩაწერა სხვადასხვა ოპერაციაა — შესაძლებელია ანგარიში წარმატებით შეიქმნას, ხოლო საწყისი ნაშთის ჩაწერა შეცდომით დასრულდეს.
  - გატარებების პირდაპირი იმპორტისას თითოეული საბუთი ცალ-ცალკე იწერება — ერთი საბუთის შეცდომის მიუხედავად, მანამდე გაგზავნილი სხვა საბუთები ვებ-სუპერფინში შეიძლება უკვე ჩაწერილი იყოს.
- **შედეგების გადამოწმება ხელახალ გაშვებამდე**:
  - თუ სამუშაო ასლში უკვე არსებობს სტატუსის ჩანაწერები (**„შედეგი“** / `OK`), შეინარჩუნეთ ისინი და შეცდომები მათი გათვალისწინებით გადაამოწმეთ (არ ივარაუდოთ, რომ ყველა სკრიპტი უკვე წარმატებულ სტრიქონებს ავტომატურად გამოტოვებს).
  - სერვერის მხარეს არ მოქმედებს „ორისის“ წყაროს რიგების ავტომატური უნიკალურობის კონტროლი — მთლიანი ფაილის უპირობოდ ხელახლა გაშვებამ შეიძლება გატარებების დუბლირება გამოიწვიოს.
  - ამიტომ ხელახალ მცდელობამდე შეამოწმეთ როგორც მოდელის შედეგების ველები, ისე უშუალოდ ვებ-სუპერფინის **„ანგარიშები“** და **„საბუთები“** გვერდები, და მხოლოდ წარუმატებელი/დარჩენილი ჩანაწერები გაასწორეთ და დაატვირთეთ.
- **მოდელით შექმნილი საბუთის შემდგომი რედაქტირებისა და წაშლის უფლება**: პირდაპირი იმპორტის მოდელით შექმნილი საბუთები ვებ-სუპერფინში იწერება მოდელების იმპორტის სერვისის სახელით. ასეთი საბუთის ჩვეულებრივი რედაქტირებისთვის მომხმარებელს (მათ შორის მთავარ ბუღალტერსაც) ჩართული უნდა ჰქონდეს უფლება **„არედაქტირებს მოდელების იმპორტის სერვისის მიერ განახლებულ საბუთებს“** ([მომხმარებლები და უფლებები](https://supports.gss.ge/ka/info/public-qa-document/68/e3cf7ba4-0120-452c-aec8-ae995443ba9b) · [მომხმარებლის უფლებების რედაქტირება](https://supports.gss.ge/ka/info/public-qa-document/68/16C6zJMRId27NcWfJjBoOzRq4DD3mvQKHbL0CVLPewx4)), ხოლო საბუთების წაშლის წესები და გამონაკლისები იხილეთ გზამკვლევში [საბუთების შექმნა, რედაქტირება და წაშლა](https://supports.gss.ge/ka/info/public-qa-document/68/dd850e29-d48e-47a3-9a52-973f3b71978e).
- **თუ მოდელის ღილაკი არ რეაგირებს**: ღილაკზე დაჭერისას შეფერხება ყოველთვის მხოლოდ ავტორიზაციის პრობლემას არ ნიშნავს — შეამოწმეთ Google Sheets-ის მიერ გამოტანილი ნებართვის მოთხოვნა ან შეცდომის ტექსტი და საჭიროებისას იხილეთ [Google Sheets რეპორტების სკრიპტის ავტორიზაცია](https://supports.gss.ge/ka/info/public-qa-document/68/198-UrxHcaeaIOp--eioWPKEYPin8FxHDg70ysUy-jXU). უკვე შევსებული სამუშაო ასლი ან შედეგების ჩანაწერები გადაუმოწმებლად არ წაშალოთ.
