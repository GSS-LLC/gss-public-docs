# ვებ-სუპერფინი: დაკავშირებული პროგრამები — კომპიუტერის სუპერფინი და API

## კომპიუტერის სუპერფინთან დაკავშირების წინაპირობები და კავშირის კოდის მიღება

ვებ-სუპერფინის გვერდზე **„დაკავშირებული პროგრამები“** იმართება ორგანიზაციის სინქრონიზაცია კომპიუტერის სუპერფინთან და მომხმარებლის პირადი `API` კავშირები. გვერდი **„დაკავშირებული პროგრამები“** ხელმისაწვდომია **ბუღალტრის**, **მთავარი ბუღალტრისა** და **დამთვალიერებლისთვის** (მხოლოდ **ადმინისტრატორის** რეჟიმში ეს გვერდი ხელმისაწვდომი არ არის).

> **დაკავშირებული გზამკვლევები და ვიდეო ინსტრუქციები:** [მომხმარებლები და უფლებები](https://supports.gss.ge/ka/info/public-qa-document/68/e3cf7ba4-0120-452c-aec8-ae995443ba9b) · [Google Sheets ანგარიშგებები](https://supports.gss.ge/ka/info/public-qa-document/68/793c0465-3814-4a6f-9ee8-bb2e77d97482) · [გარე საბუღალტრო მოდელებიდან იმპორტი](https://supports.gss.ge/ka/info/public-qa-document/68/fa7514ab-2d4d-45f9-8506-c41006d4b7f5) · [ვიდეო: სუპერფინისა და ვებ-სუპერფინის სინქრონიზაცია](https://www.youtube.com/watch?v=6upV-avrB74) · [ყველა ვიდეო ინსტრუქცია YouTube-ზე](https://www.youtube.com/@mygssge/playlists).

კომპიუტერის სუპერფინთან კავშირის დასამყარებლად აუცილებელია შემდეგი წინაპირობების დაცვა:

- **უფლებამოსილება** — კომპიუტერის სუპერფინთან ახალი კავშირის დამატება, კავშირის კოდის განახლება და კავშირის წაშლა შეუძლია მხოლოდ **მთავარ ბუღალტერს**;
- **ძირითადი ვალუტა (`GEL`) და ერთი აქტიური კავშირის შეზღუდვა** — კავშირის გააქტიურებისას მოწმდება, რომ ვებ-სუპერფინის ორგანიზაციის ძირითადი ვალუტა იყოს ლარი (`GEL`) და ორგანიზაციას ჰქონდეს მხოლოდ ერთი აქტიური კომპიუტერის სუპერფინის კავშირი.

**დაკავშირების კოდის მიღება და განახლება:**
1. გადადით გვერდზე **„დაკავშირებული პროგრამები“** და ინსტრუმენტების ზოლში დააჭირეთ ღილაკს **„სუპერფინთან ახალი კავშირი“**.
2. სისტემა პირდაპირ შექმნის კავშირის ჩანაწერს და თქვენს ელფოსტაზე გამოაგზავნის **დაკავშირების კოდს**, რომლის მოქმედების ვადაა **`15` წუთი**.
3. თუ წერილის გაგზავნა შეფერხდა, `15`-წუთიანი ვადა ამოიწურა ან უკვე დაკავშირებული კომპიუტერის სუპერფინი ითხოვს კავშირის კოდის განახლებას, ახალი ჩანაწერის შექმნის ნაცვლად არსებული სტრიქონის გასწვრივ დააჭირეთ ღილაკს **„კავშირის კოდის (API Code) განახლება“** ახალი `15`-წუთიანი კოდის მისაღებად.

## კავშირის კოდის შეყვანა კომპიუტერის სუპერფინში და მომხმარებლის შესაბამისობა

წყაროს ოფიციალური ინსტრუქციის მიხედვით, ვებ-სუპერფინიდან ელფოსტაზე მიღებული `15`-წუთიანი კოდის გასააქტიურებლად კომპიუტერის სუპერფინში სრულდება შემდეგი ნაბიჯები:

1. გახსენით კომპიუტერის სუპერფინი და გადადით მენიუში **„პარამეტრები“ → ჩანართი „gss.ge“**.
2. დააჭირეთ ღილაკს **„დაკავშირება/კავშირის წაშლა“**, შეიყვანეთ ელფოსტაზე მიღებული დაკავშირების კოდი და დაადასტურეთ.
3. წყაროს ინსტრუქციის მიხედვით, იმავე ჩანართში (**„პარამეტრები“ → „gss.ge“**) მოცემულია სინქრონიზაციის პარამეტრები:
   - **„superfin.gss.ge - საბუთების ავტომატური სინქრონიზაცია“** — საბუთების ავტომატური მიმოცვლის ჩართვა/გამორთვა;
   - **„პროგრამაში შესვლისას შემატყობინე სინქრონიზაციის გათიშვის შესახებ“** — შეხსენება ავტომატური სინქრონიზაციის გამორთული მდგომარეობისას;
   - **„superfin.gss.ge-ზე შექმნილი საბუთების მომხმარებელი“** — კომპიუტერის სუპერფინის საერთო მომხმარებელი, რომლის სახელითაც აისახება ვებ-სუპერფინიდან გადატანილი საბუთები მაშინ, როცა ვებ-სუპერფინის გვერდზე **„მომხმარებლები“** კონკრეტულ წევრს ველი **„მომხმარებლის სახელი პროგრამა - სუპერფინში“** შევსებული არ აქვს (იხილეთ [მომხმარებლები და უფლებები](https://supports.gss.ge/ka/info/public-qa-document/68/e3cf7ba4-0120-452c-aec8-ae995443ba9b)).

## კომპიუტერის სუპერფინთან კავშირის გაუქმება

ვებ-სუპერფინში კომპიუტერის სუპერფინის ჩანაწერის წაშლა შეუძლია მხოლოდ **მთავარ ბუღალტერს**. წაშლის მიმდინარეობა დამოკიდებულია იმაზე, დასრულებული იყო თუ არა კომპიუტერის სუპერფინთან დაკავშირება:

- **თუ კავშირი ჯერ არ გააქტიურებულა:** გვერდზე **„დაკავშირებული პროგრამები“** ღილაკზე **„წაშლა“** დაჭერისას ჩანაწერი პირდაპირ იშლება დამატებითი დადასტურების დიალოგისა და კოდის გარეშე;
- **თუ კომპიუტერის სუპერფინთან კავშირი უკვე აქტიურია:**
  1. გვერდზე **„დაკავშირებული პროგრამები“** სუპერფინის სტრიქონზე დააჭირეთ ღილაკს **„წაშლა“**.
  2. გამოჩნდება სავალდებულო მოსანიშნი ველი **„superfin.gss.ge პორტალზე შეტანილი ინფორმაცია გახდეს 'გასარკვევი' და შემოწმდეს“** — მონიშნეთ იგი და კვლავ დააჭირეთ ღილაკს **„წაშლა“**.
  3. თქვენს ელფოსტაზე გამოიგზავნება **კავშირის გაუქმების კოდი** (მოქმედების ვადა — **`15` წუთი**).
  4. კავშირის საბოლოოდ გასაწყვეტად შეიყვანეთ მიღებული კოდი კომპიუტერის სუპერფინში: **„პარამეტრები“ → ჩანართი „gss.ge“ → „დაკავშირება/კავშირის წაშლა“**.

## პირადი API კავშირის შექმნა, Secret-ის ნახვა და წაშლა

ვებ-სუპერფინის გარე ანგარიშგებებთან (`Google Sheets`) ან საბუღალტრო მოდელების იმპორტთან დასაკავშირებლად გვერდზე **„დაკავშირებული პროგრამები“** იქმნება მომხმარებლის პირადი **`API`** კავშირი:

1. **პირადი `API` კავშირის შექმნა:**
   - გვერდზე **„დაკავშირებული პროგრამები“** ინსტრუმენტების ზოლში დააჭირეთ ღილაკს **„ახალი API კავშირი“**;
   - შექმნილი `API` გასაღები ეკუთვნის უშუალოდ **მიმდინარე მომხმარებელს** (პირადი `API` კავშირის შექმნა არ არის შეზღუდული მხოლოდ მთავარი ბუღალტრით, ხოლო სხვა მომხმარებლების პირადი `API` გასაღებები ჩვეულებრივ სიაში არ ჩანს).
2. **საიდუმლო გასაღების (`Secret`) ერთჯერადი ნახვა:**
   - საკუთარი `API` ჩანაწერის სტრიქონზე დააჭირეთ თვალის ხატულას (**„Secret-ის ნახვა“**);
   - სისტემა თქვენს ელფოსტაზე აგზავნის **`Secret`-ის სანახავ ერთჯერად ბმულს**, რომლის მოქმედების ვადაა **`15` წუთი** (განასხვავეთ ეს ბმული კომპიუტერის სუპერფინის 15-წუთიანი დაკავშირების კოდისგან);
   - ბმულის გახსნისას ეკრანზე გამოჩნდება `Secret` კოდი და ერთჯერადი ბმული მაშინვე იხარჯება. თუ ბმული უკვე გამოიყენეთ ან `15`-წუთიანი ვადა გავიდა, ახალი `API` კავშირის შექმნა საჭირო არ არის — იმავე სტრიქონზე კვლავ დააჭირეთ თვალის ხატულას (**„Secret-ის ნახვა“**) ახალი ერთჯერადი ბმულის მისაღებად.
3. **უსაფრთხოება და პირადი `API` კავშირის წაშლა:**
   - `API` გასაღები პერსონალურია და მოქმედებს მისი მფლობელი მომხმარებლის უფლებებით — არ გადასცეთ პირადი `API` გასაღები სხვა პირს და არ აურიოთ იგი ბანკის ინტეგრაციის კოდებში (საქართველოს ბანკის `Secret` ან თიბისი ბანკის `API-Key`);
   - პირადი `API` კავშირის გასაუქმებლად მის სტრიქონზე დააჭირეთ ღილაკს **„წაშლა“**, გამოჩენილ ველში მონიშნეთ **„ვეთანხმები 'API სერვისთან' კავშირის წაშლას“**, კვლავ დააჭირეთ ღილაკს **„წაშლა“** და გადაამოწმეთ, რომ ჩანაწერი სიიდან გაქრა ([Google Sheets ანგარიშგებები](https://supports.gss.ge/ka/info/public-qa-document/68/793c0465-3814-4a6f-9ee8-bb2e77d97482) · [გარე საბუღალტრო მოდელებიდან იმპორტი](https://supports.gss.ge/ka/info/public-qa-document/68/fa7514ab-2d4d-45f9-8506-c41006d4b7f5)).
